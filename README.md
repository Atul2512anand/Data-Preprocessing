# Data Cleaning & Preprocessing 🛳️

This project covers full preprocessing of the Titanic dataset using Python and Google Colab, with visual analysis using seaborn and matplotlib.

## 📌 Tasks Covered
- ✅ Load dataset via `kagglehub`
- ✅ Handle missing values (`Age`, `Embarked`)
- ✅ Drop unneeded columns (`Cabin`)
- ✅ Encode categorical features (`Sex`, `Embarked`)
- ✅ Normalize numerical features (`Age`, `Fare`)
- ✅ Detect and remove outliers using IQR
- ✅ Visualize all steps: missing values, distributions, boxplots

## 📁 Files Included
- `data_preprocessing.ipynb`: Full Colab notebook
- `titanic_cleaned.csv`: Final cleaned dataset
- `Titanic-Dataset.csv`: Raw dataset (optional)
- `screenshots/`: Visual graphs of each step (optional)
- `README.md`: This file
